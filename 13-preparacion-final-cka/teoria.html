📘 Teoría

Por qué la velocidad gana el CKA

El examen da ~15-20 tareas en 2 horas. Escribir un pod YAML a mano cuesta ~2 min; generarlo imperativamente cuesta ~10 segundos.

kubectl run / create / expose --dry-run=client -o yaml > base.yaml   ← genera el esqueleto
kubectl explain <recurso>.<campo> --recursive                      ← estructura sin abrir docs
kubectl get ... -o jsonpath / custom-columns / --sort-by           ← extrae solo lo que piden
kubectl config use-context <ctx>                                   ← ¡SIEMPRE el 1er comando!
Regla de oro: el primer comando de CADA pregunta es cambiar al contexto correcto. Resolver en el cluster equivocado = 0 puntos.

Multiple Schedulers y Scheduler Profiles

El kube-scheduler por defecto no es el único posible. Puedes desplegar un segundo scheduler y hacer que pods específicos lo usen vía spec.schedulerName. Los Scheduler Profiles permiten que un mismo binario exponga varios perfiles nombrados.

Pod sin schedulerName           ──▶  default-scheduler
Pod con schedulerName: mi-sched ──▶  tu scheduler / perfil personalizado
