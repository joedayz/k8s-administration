👤 Rol del administrador

Instalar y configurar clusters de Kubernetes desde cero es una habilidad fundamental del CKA:

  • Entender qué componentes se instalan y cómo interactúan
  • Crear clusters con kubeadm y con k3s

Instalación con kubeadm (workflow del examen CKA)

# 1. En TODOS los nodos: instalar containerd, kubelet, kubeadm, kubectl
apt-get update && apt-get install -y containerd kubelet kubeadm kubectl

# 2. En el control plane: inicializar el cluster
kubeadm init --pod-network-cidr=10.244.0.0/16

# 3. Configurar kubeconfig
mkdir -p $HOME/.kube
cp /etc/kubernetes/admin.conf $HOME/.kube/config

# 4. Instalar CNI (Flannel)
kubectl apply -f https://.../kube-flannel.yml

# 5. En cada worker: unir al cluster
kubeadm join :6443 --token  --discovery-token-ca-cert-hash

Instalación con k3s

# En el server (single-node o primer master)
curl -sfL https://get.k3s.io | sh -

# En cada worker
curl -sfL https://get.k3s.io | K3S_URL=https://:6443 K3S_TOKEN= sh -

Alta Disponibilidad (HA)

Un cluster HA tiene múltiples nodos control plane para que si uno cae, el cluster sigue funcionando.

TopologíaDescripciónCuándo usar
Stacked etcdetcd corre en cada nodo masterClusters pequeños/medianos
External etcdetcd en nodos separadosProducción crítica
 
                  ┌─── Load Balancer (HAProxy) ───┐
                  │          VIP: 192.168.1.100     │
                  └───┬──────────┬──────────┬─────────┘
                      ▼          ▼          ▼
                   Master 1   Master 2   Master 3
                   (etcd)     (etcd)     (etcd)
Requisitos mínimos para HA: 3 nodos master (quórum de etcd = 2f+1).
